

# Lab 4.1, Variables and Functions

## Description
In this lab functions are made to return conditional response based on variable inputs.<br>
Task 1: a full name is formatted from a first and last name. <br>
Task 2: a total cost is checks for input validity and then calculates based on price, quantity, and tax <br>
Task 3: eligibility of an individual is determined based on inputs <br>
Task 4: task 2 is updated to handle discounts

## Running the program
To use view the results of this lab and sample outputs, run "node index.js" in vscode.

## Reflection Questions
> How did you approach creating more flexible functions with parameters?

Functions for repeated tasks were given parameters, which means the values for their inputs do not need to be defined or changed before they are called.
<br>

> What challenges did you face while incorporating conditional logic in your functions?

Multiple conditions had to be chained together using an && operator. <br>
Off-by-one errors had to be avoided when checking numerical value. <br>
">" and ">=" must be selected carefully.
<br>

> How does refactoring improve the readability and maintainability of your code?

Refactoring improves readability and maintainability by providing consistency and simplicity.
